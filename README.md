# Hari-hotel-manegement
🏨 Hotel Management System is a responsive frontend web application showcasing hotel rooms, booking options, facilities, restaurant services, and pricing through a modern and user-friendly interface.
🏨 Hotel Management System

A modern and responsive Hotel Management System designed to provide an easy and convenient hotel booking experience. Users can explore rooms, view facilities, check prices, and discover hotel services through an attractive interface.

✨ Features

- 🏨 Hotel Room Display
- 🛏️ Room Categories
- 📅 Room Booking Interface
- 💰 Room Price Details
- 🍽️ Restaurant & Food Services
- 🛎️ Hotel Facilities
- 📍 Contact & Location Details
- 📱 Responsive Design
